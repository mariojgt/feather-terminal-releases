These links follow the latest complete published release. A release becomes available only after all platform builds succeed.

Each release includes `SHA256SUMS.txt` and a `release.json` download manifest. Install Git and your preferred coding-agent CLI separately, and sign in with your own accounts.

Feather Terminal is a developer preview. Windows and Linux builds are experimental. Unsigned Windows installers and macOS builds without notarization may need approval from your operating system.

This repository distributes installers only. Application source code is maintained separately; the automatically generated source archives here contain only this download repository.
